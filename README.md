# EvoStream Sentiment 🧬

> **Status:** 🚧 Work in Progress

## Overview
This repository contains the implementation for the master's thesis: **Adaptive Genetic Algorithms for Optimizing Language Embedding Clustering in Real-time Sentiment Analysis of Data Streams**. The goal is to build a real-time system that uses genetic algorithms to continuously adapt clustering parameters to evolving data streams (e.g., social media), outperforming static methods like K-means or DBSCAN.

## Tech Stack
* **Data Pipeline:** Apache Kafka
* **Logic:** Python, Adaptive Genetic Algorithms, NLP Embeddings
* **Infrastructure:** Docker, `uv` for dependency management
